# Outputs

Long-form documents synthesized **from** the wiki and written for a reader outside this vault.
Unlike `wiki/` pages (atomic concepts, maintained in place), these are whole documents with an
intended audience. See the Publish workflow in [AGENTS.md](../AGENTS.md#workflows).

Every output belongs in this catalog. Outputs are entry points for outside readers rather than
nodes in the graph, so nothing else links to them — this index is how they get found.
