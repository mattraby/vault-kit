# Sources

Raw, **immutable** source material: articles, transcripts, exports, PDFs, screenshots. Each
source gets a thin wrapper page carrying provenance and a link to the archived original; the
originals themselves live in each topic's `attachments/` folder and are assets, not pages.

We read these and cite them. We never edit their content. See [AGENTS.md](../AGENTS.md) for the
Ingest workflow.
